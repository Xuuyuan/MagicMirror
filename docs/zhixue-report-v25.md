# 智学网新版报告与旧版兼容

报告版本按当前考试的官方模块和指标权限选择，不按登录角色、考试年份或一次请求失败猜测。平台差异封装在 Provider；UI 消费统一的报告卡片与雷达轴信息。

## 选择与权限

先读取新版 `common/getModules`（`ZXB_REPORT_EXAM_V25`、`ZXB_NEW_REPORT`）。包含 v2025 模块时读取 `queryModuleIndicatorPermission` 并使用新版协议；缺少新版模块或该元数据端点明确不支持时，只在官方旧模块明确提供 `completeReportMain` 的情况下使用旧链路。网络失败、权限拒绝、会话失效和未知结构不自动切换到旧接口。

新版服务使用已验证的 `ali-bg.zhixue.com/api-parentReport/report/`，请求带官方签名、`sucUserToken` 头和官方要求的 token 参数。Token 不进入界面路由、文档或测试夹具。旧服务保留原来的请求头与路由合同。

进入单科时重新读取指标权限和 `ZXB_REPORT_PAPER_V25` 模块；请求内部复用这次结果。缓存继续使用 TanStack Query 既有账号、revision、考试、学科键，不新增成绩内容缓存。

## 已接入

- 新版主报告：分数、原分/赋分及满分、等级和明确缺考标记。权限关闭的分数与等级不进入输出。原生界面保留成绩单等级，不用分数型趋势等第覆盖。
- 等级变化：总分页只有模块、showLevelFlag 和 setLevel 同时开放才请求。按当前考试 ID 精确匹配，以主报告校正当前点，不修改历史和源对象，不借用旧班级/学校/联考人数估算排名。新版科目详情不再显示或请求等级变化卡片。
- 标准分与得分率变化：按当前指标和模块选择，以明细表展示。零值有效，未开放的得分率分项不显示。当前实测场次未开放这两类，已用虚构数据验证分支，真实样本仍待补充。
- 学科均衡：放在近五次成绩变化下方。读取 `getSubjectBalance` 的 thisLevel/usualLevel/mediumLevel，使用有符号轴及年级参照线。范围为最大绝对值向上扩一整数的对称区间；保留空缺，不把数值变成名次或百分比。旧雷达默认仍为 0～100，不改变旧数据方向。
- 小题作答：读取 `getAnswerInfo`，按题号合并已验证答题元数据，保留零分；单科模块关闭不发起请求。新版各题 `gradeAvgScore` 显示为校均，整科均分用全部顶层小题原始均分相加后保留两位小数，缺失均分、空列表或重复题号时不推算整科均分，不对各题先舍入再求和，也不把子题重复计入。赋分科目注明为原分均分；只看错题不重算整科均分。旧版不新增均分推算。
- 知识点：按用户要求，新版科目详情不再显示或请求知识点掌握卡片。
- 答题图像：模块和 showDownloadOriginalPaper 开放时读取新版 `getCheckSheet`。单独验证数组式图片列表和控制字段，把字符串选题标记、子题列表规范化后复用旧解析器。图片仍按需加载；只有模板通过既有区域校验才提供逐题切图，未知模板保留整页访问。
- 解析/正确答案补充：仅在官方模块、showDownloadOriginalPaper、showKnowledge 均允许时调用新版分析接口。失败不丢掉已有小题得分，权限或会话错误不借用旧路径绕过。

新版总分与单科模块可以共存旧趋势：只有官方默认分支（缺少配置等级或等级指标未开放）才保留旧趋势卡片，不拼接两种等级刻度。总分的“2B/4C”等是科目等级汇总，不当作单一总分等级或排名依据。

用户已在 MuMu 确认本场学科均衡图、物理小题及两页答题卡（包含缩放、返回）均正常。其它旧考试、家长会话、方向总分专门交互、不同学校禁用配置、标准分及得分率真实样本尚未逐项验证；不把本场通过泛化为所有报告均通过。现有普通总分不被未适配的方向总分覆盖。

不自动执行标记已读、归档图片恢复、生成文件、验证码、绑定或其它业务写入。官方未开放模块保留未开放状态。
