# 智学网逐题作答区域

## App 行为

单科逐题得分中，存在完整定位信息的主观题显示“查看作答”；共享同一套完整作答区域的合并阅卷题仅在最后出现的可见题目显示入口。点击后使用原有图片预览界面，支持双击、捏合缩放与拖动。同题多个区域按页码、模板中的区域顺序展示，通过“上一区域 / 下一区域”切换，显示当前区域序号；切换时重置缩放。

作文可以包含三个独立区域，三者均保留，不将首个区域当作整题。无法可靠定位时不生成逐题入口，仍可查看整页答题卡。当前展示原始扫描作答，不叠加未验证的批阅笔迹或逐点得分。

区域预览暂不提供长按保存/复制，避免将底层整页原图误当成该题裁剪图。整页预览保留原有长按操作。

## 数据与统一接口

复用现有网页登录会话和只读 `checksheet/` 响应，不新增认证方式或中转服务，不依赖报告模块配置。读取前后检查当前学生，考试及科目必须属于当前会话；图片地址沿用官方签名地址，不附加登录请求头。

- `sheetDatas.userAnswerRecordDTO.answerRecordDetails` 提供题目记录。
- `sheetDatas.answerSheetLocationDTO.pageSheets[].sections[].contents.branch[]` 提供作答区域。
- `branch.ixList` 是题目记录的 **1 起始索引**，不是内部题号或印刷题号。
- `branch.position` 为区域位置，`pageIndex` 对应 `sheetImages` 的页索引。
- 当前解析 `comeFrom=0` 的 A3（420×297 mm）、A4（210×297 mm）模板。实际会话已验证 A3；A4 使用对应尺寸并有虚构数据换算测试，尚无真实样本验证。
- 区域转换为相对原图的 `x/y/width/height`。预览验证原图宽高比，再以裁剪窗口展示；不修改签名 URL，不生成错误裁剪的永久缓存。
- 多题共享同一套完整有效作答区域时，仅在最后出现的可见题目显示“查看作答”，其它题目的得分照常保留。预览标明关联题号和“合并作答区域”，不猜测各题的独立裁切边界。若某题另有独立区域，不按仅部分共享去合并入口。任一关联索引越界、页码或坐标无效时不采纳该区域。
- 未知模板、未解析引用或同题任一区域无效时，不返回不完整作答。未选的选做题、未验证的子题不借用父题区域。

统一模型 `AnswerSheet.region?: ImageRegion` 表示归一化区域，普通 `AnswerSheet` 保持兼容。Provider 可选实现：

```ts
getQuestionAnswerSheets(session, examId, subjectId, questionId, cachedResult?, options?): Promise<AnswerSheet[]>
```

调用方优先使用多区域方法，复用 TanStack Query 中已有考试结果及请求取消信号。旧平台的 `getQuestionAnswerSheet` 单图方法继续使用；题干、参考答案图片沿用原有来源与请求头。

## 验证与限制

虚构数据测试覆盖跨页多区域、索引映射、重复区域、缺失/歧义定位、合并题仅保留最后可见入口、末题未选时回退到前一可见题、共享区域无效时隐藏入口、学生变化、旧单图方法兼容、请求取消信号传递、坐标边界、三次区域展示与缩放重置。组件测试使用模拟的 React Native 控件，不代替原生布局和手势验收。

原生交互尚未验收，需在 Android 调试 App 中完成：

1. 进入有多区域作文的科目，打开“查看作答”，依次切换各区域，检查完整书写、页序和当前区域序号。
2. 分别缩放、拖动，再切换区域确认复位；返回后检查普通问答题与整页答题卡，区域预览不提供长按保存/复制，整页预览仍保留长按操作。
3. 打开合并阅卷题（如同组的 12–14 题），确认仅最后出现的可见题目有“查看作答”，各题得分仍保留；预览标明关联题号及“合并作答区域”，展示完整共享范围，跨页时可切换全部区域。
4. 对共享区域之外另有独立区域的题目，确认不会仅因局部重合而隐藏独立入口；选做题未选、区域无效或无法定位时，不显示误导性的入口。
