# 成绩显示偏好

设置页的“成绩显示”区域包含以下本机偏好，修改即时生效、重启后保留，适用于本机全部账号。

两项偏好使用下拉选择，收起时只展示当前值，文字居左、箭头居右；选项菜单从选择框下方展开，选择后自动收起。

- **显示缺考科目**：默认“显示”；选择“隐藏”仅过滤考试详情中明确标记 `status: absent` 的科目，不按零分或分数缺失推断缺考，不修改 Provider 数据、成绩缓存、总分或考生人数。
- **七天学堂-等第显示方式**：默认“等第及百分比均显示”，也可选择“只显示等第”“只显示百分比”“不显示”。统一影响总分徽标、科目卡片和单科详情，其他平台保持原有展示。
- 仅显示百分比时，平台没有提供对应百分比则隐藏徽标，不推算或回退显示等第。

偏好使用现有 Zustand store 和 SecureStore 的 `magicmirror.ui.v1` 保存，不新增存储依赖。旧配置缺少字段、字段类型不符或存储损坏时使用默认值，保留主题设置兼容性。格式策略集中于 `src/services/score-display.ts`，页面复用 `GradeBadge`。

## 人工验收

1. 首次或旧配置进入设置，确认默认显示缺考、等第及百分比。
2. 切换“隐藏”，回到考试详情确认仅缺考卡片隐藏；切回“显示”后恢复，零分科目始终保留。
3. 在七天账号下逐一切换四种等第模式，核对总分、科目卡片和单科详情一致。
4. 切换其他平台账号，确认等第显示不受七天设置影响。
5. 退出并重启 App，确认选项恢复，主题及主题色没有被覆盖。

设置动作、状态订阅、三个页面显示及存储恢复由隔离测试覆盖；原生设置页布局和实体设备重启流程仍需人工验收。
