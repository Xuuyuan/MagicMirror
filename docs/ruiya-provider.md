# 睿芽 Provider

- 官方域名：`https://ruiya.onlyets.com`。
- 登录方式：官方 ASP.NET 表单、官网 RSA 密码加密及会话 Cookie；凭据由应用安全存储管理。保留睿芽的 HTTPS 和手工 Cookie 请求方式。
- 与百分智复用 `createRuiyaProvider` 及统一报告模型；睿芽注册实例启用 `extendedReports`，学能接口使用官网的 `getByAbilityScore`。

## 支持内容

考试列表保留官方未开放报告；已开放考试支持原始分/赋分、排名及总人数、缺考标识、学科超过比例、班级位置和总分分数线。

考试详情从官方试卷元数据读取单科卷面满分；按统一展示约定，只在主分数（含赋分）后展示满分，原始分旁不重复展示，科目详情同样处理。仅当各科试卷元数据完整、试卷无重复且原始分合计与官方原始总分一致时合计总满分。

科目详情支持逐题得分、客观题答案、按需请求主观题作答裁图、整卷答题卡、题型汇总、题组得分率、章节及能力分析。学能分析仅在官方明确开放时展示。裁图支持官方返回的 HTTP 图片和 Base64 位图。

共享页面使用“超过比例”，总分分数线直接展示；不展示能力分析说明和试卷信息卡片，科目排名总人数使用较小字号，作答裁图加载弹窗通过空白区域关闭。

## 限制与验证

- 仅查询账号正常有权访问的官方数据；不绕过报告开放状态。
- 附加分析失败时保留基础成绩和逐题数据；缺少可靠的题型或完整性证据时不生成题型汇总。
- 不推断缺失的题目图片、视频或正确答案；只展示接口提供的内容。
- 睿芽不使用百分智的跨域系统 Cookie 容器配置。
- 2026-10-08 的只读接口核验确认：六科逐题、题组、章节、能力和裁图结构兼容共享解析；旧 `getAbilityScore` 返回 404，官网 `getByAbilityScore` 可用但该账号未开放学能分析。此核验不等于原生页面验收。
- 启用后的实际注册 Provider 已通过真实账号只读验证：六科共 158 道题，六科的题型汇总、排名总人数、题组分析、整卷答题卡和按需裁图均成功解析；未开放学能分析保持隐藏。自动化测试使用虚构数据，真实核验只保存结构及计数，不保存认证信息或原始成绩。
- 2026-10-08 已在 MuMu + Expo Go 完成原生页面交互验收：登录、六科详情与返回、分析展开收起、错题筛选、裁图加载空白关闭、图片放大拖动、长按保存到相册、整卷答题卡预览通过；科目排名总人数使用较小字号，未开放学能分析隐藏。此账号没有已开放学能报告、视频或题干图片，相关内容不列为真实页面验收通过。
