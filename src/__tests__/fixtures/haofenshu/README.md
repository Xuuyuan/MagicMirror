# 好分数离线验证样例

这四份 JSON 均为虚构测试数据，供 `node tools/verify-haofenshu.cjs --offline` 使用，不含真实账号、密码、Token、成绩或学生信息。

样例保留原有版本与字段说明。脚本将旧版考试列表的第一场考试转换为虚构的 v4 档案响应，将总览中的排名展示字段转换为 v4 形态，并构造空的配置响应。这些适配只用于离线验证，不代表真实接口返回已得到验证。

JSON 元数据提到的 `captures.md` 是本地研究记录，不属于公开仓库。真实抓包、测试账号和反编译材料仍应放在被忽略的 `analysis/` 中，不得替换这些虚构样例。
